## 本地运行

浏览器出于安全策略，禁止 `file://` 打开的页面把画布导出成图片（点「保存」或「复制图片」会报 `SecurityError: Tainted canvases may not be exported`），所以要用本地服务器打开，而不是直接双击 `drawline.html`。

在仓库根目录执行任意一条命令：

```bash
python -m http.server 8765
# 或者
npx serve -l 8765
```

然后浏览器访问 <http://127.0.0.1:8765/drawline.html>。用 VS Code 的话，装 Live Server 插件后右键 `drawline.html` → Open with Live Server 也可以。

`localhost` / `127.0.0.1` 属于安全上下文，剪贴板 API 可以正常使用，所以「复制图片」在本地服务器下才能真正把图片写进系统剪贴板。

## 用法

每个输入框对应一个气泡，从上到下依次排开，行距 24px。第一个气泡带小尾巴，后面几句是干净的圆角气泡，左边缘和第一句对齐。

- **+ 加一句**：在下面追加一个输入框，多一句就多一个气泡。
- 输入框右侧的 **×**：删掉这一句，剩下的自动重新编号。
- 留空的句子不会画出气泡，所以草稿阶段可以放心多加几行。

句子太长时气泡会自动折行：单行超过约 16 个汉字就换行，并且会尽量让每行长度接近，不会出现末行只剩两三个字的尴尬。汉字逐字断行、英文按单词断行，标点不会孤零零掉到下一行开头。气泡高度随行数增长，圆角保持不变。

文字宽度用 `measureText` 实测——汉字、英文、数字各按自己的字宽计算，不再按字符数估算导致气泡过长或过短。

- **重置**：清空所有句子，只留一个空输入框，微调量一并归零。
- **保存**：把当前图片下载成 PNG，文件名取第一句的文字。
- **复制图片**：一键把图片写入系统剪贴板，可以直接粘到微信、QQ、钉钉等聊天窗口；某些环境下浏览器会拒绝写入，此时会自动改为下载图片。
- **框拉长一点 / 框缩短一点**：给「当前选中的那一句」在自动长度的基础上微调 ±12px。
- **长度微调**滑条：同样作用于当前选中的那一句，以自动长度为中心整体缩放（50 为 1 倍，范围 0～100 对应 0.5～1.5 倍），拉条和数字框双向同步。

哪一句是「当前选中」的？就是你最后点过的那一行，左侧会有一条深色竖线作为标记，滑条旁边也会显示「（第 N 句）」。这样多气泡的时候可以单独把某一句拉长一点。
